## Projects

### 🔍 Quellen-Finder — semantic source finder for academic writing

You paste a paragraph from your thesis draft. It tells you which PDF on your laptop it came from, and on which page — even when you paraphrased it heavily, and even across languages.

Built as a retrieval pipeline: PDFs chunked into ~800-character passages with LangChain, each embedded into a 768-dimension vector using a multilingual HuggingFace model, indexed in Pinecone alongside filename and page metadata. A textual-overlap check runs next to the semantic match, so you can see whether a direct quote or a paraphrase is the honest choice.

`Python` · `LangChain` · `HuggingFace` · `Pinecone` · `Streamlit`
